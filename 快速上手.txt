【怎么打开】
  双击「语法填空刷题系统.html」→ 用 Chrome 或 Edge 打开。
  不需要联网、不需要安装、不需要账号。

────────────────────────────────────────────────────────────
【老师】
────────────────────────────────────────────────────────────
1. 进教师模式：右上角「教师」→ 口令 2468 → 验证
   ⚠ 第一次用请到「教师设置」改掉默认口令！

   快捷导航：右侧「快捷导航」区点题号按钮（56–65）→ 原文自动滚到那一空
   · 整页自动滚动把该空送到眼前，不用手动上下翻找
   · 当前题按钮荧光绿高亮，与短文高亮同步
   · 核对过的题按钮上带 ✓/✗，讲评找易错题很方便

2. 打印试卷：顶部「打印」
   · 只打印题目        → 发给学生
   · 题目 + 答案一起   → 老师留底讲评
   · 打印单词本        → 生词默写（学生也能打印）
   · 打印错题本        → 提交后自动收录的错句
   ☑ 连同教师手写笔记  → 把批注一起印出来
   ⚠ 打印对话框必须勾选「背景图形」，颜色才会出来
   ⚠ 存 PDF：目标打印机选「另存为 PDF」

3. 标重点（教师专属）
   顶部五色笔选颜色 → 在短文里选中文字 → 松开就上色
   · 再点已上色的字 = 取消
   · 「↶ 撤销」= 回退上一步（最多 20 步）
   · 「清空本页」= 清掉本题全部高亮

4. 手写批注
   「开笔」→ 「✒ 笔」选颜色+粗细 → 在短文上拖动书写
   · 「▤ 橡皮」擦笔迹，也能擦掉五色笔高亮
   · 「撤销」撤一笔，「清空本题」清本题
   · 再点一次工具按钮 = 收起面板；点面板外也自动收起

5. 查词（教师专属）
   点短文里的单词 → 弹出音标 + 释义
   划选一整句 → 逐词释义
   「词库管理」→ 加词 / 导入 / 导出（CSV、JSON、TXT）

6. 发授权码给其他教师
   「教师设置」→ 设有效期 → 「生成 6 位授权码」→ 告诉对方
   「收回授权」= 该码立即失效

7. 看正确率
   顶部「正确率」→ 按套卷看完成率与正确率

8. 换设备 / 备份
   顶部「导出」→ JSON 文件；新设备「导入」即可

9. 翻页笔（投影用）
   PageUp = 上一题     PageDown = 下一题

────────────────────────────────────────────────────────────
【学生】
────────────────────────────────────────────────────────────
1. 看答题卡（就是作答区）
   右侧「答题卡」竖排列出 56.______ 57.______ ……
   直接在横线里填答案；短文对应横线会同步显示
   未填 / 已填 / ✓正确 / ✗错误 一眼可见

2. 做题 + 提交答案
   顶部选套卷 → 在右侧答题卡逐空填写（也可直接在短文横线打字）
   ⚠ 必须 10 个空全部填完才能提交：没填完点「提交答案」
     会提示还差几空、把未填行标红，不判分也不出答案
   全部填完 → 点「提交答案」→ 自动批改评分
   → 填对的变绿、填错的变红，显示「得分 n/10」
   → 下方「答案分析」逐题列出：你的答案：xx　正确答案：xx
     （只有答案，没有解析；提交后自动滚到该区）

3. 重做（次数自动记录）
   点「清空重做」→ 清空本套 10 个空，重新作答
   统计条累计「重做 N 次 · 提交 M 次」
   刷新、关掉再打开都还在；导出 JSON 可备份 / 换设备导入
   ⚠ 改动任何一个已提交的答案 → 答案分析自动收起，需重新提交

4. 收集生词 + 打印默写
   点短文里的英文单词 → 自动收进单词本（底部会提示）
   再点一次 = 取消收藏
   顶部「单词本」查看全部（按收藏先后排列）
   点「打印单词本」→ 生成带音标、释义、默写横线的表格
     （学生也能打印；或顶部「打印」→ 选「打印单词本」）
   ⚠ 学生只能打印题目和单词本，答案卷仍需教师授权

5. 错题收录 + 打印复习
   提交整卷后，答错的空自动进「错题本」
   → 只收那一空的完整句子，不是整篇文章
   顶部「错题本」查看；做对后标「已订正」，仍保留
   点「打印错题本」→ 句子级错题表，可打印或存 PDF
   点「导出文档」→ 下载 HTML 文件，双击打开就能打印
   ⚠ 不含解析；导出 JSON 会把错题一起备份

6. 划重点
   「开笔」→「▨ 记号笔」选颜色和粗细 → 拖动涂画
   不用时点「收笔」

────────────────────────────────────────────────────────────
【重要提醒】
────────────────────────────────────────────────────────────
· 数据只存在这台设备的浏览器里，不会上传！
· 清除浏览器数据 / 换浏览器 / 换设备 = 数据会丢
  → 重要作业请点「导出」备份
· 开笔（涂画）状态下点单词不会有反应，先点「收笔」
· 学生模式看不到答案，这是系统锁定的
· 提交前不出答案；提交后「答案分析」只给正确答案与你的答案，没有解析
· 错题本记录随「导出」一起备份，换设备记得导入

【怎么打开】
  双击「语法填空刷题系统.html」→ 用 Chrome 或 Edge 打开。
  不需要联网、不需要安装、不需要账号。

────────────────────────────────────────────────────────────
【老师】
────────────────────────────────────────────────────────────
1. 进教师模式：右上角「教师」→ 口令 2468 → 验证
   ⚠ 第一次用请到「教师设置」改掉默认口令！

2. 打印试卷：顶部「打印」
   · 只打印题目        → 发给学生
   · 题目 + 答案一起   → 老师留底讲评
   · 打印单词本        → 生词默写
   ☑ 连同教师手写笔记  → 把批注一起印出来
   ⚠ 打印对话框必须勾选「背景图形」，颜色才会出来
   ⚠ 存 PDF：目标打印机选「另存为 PDF」

3. 标重点（教师专属）
   顶部五色笔选颜色 → 在短文里选中文字 → 松开就上色
   · 再点已上色的字 = 取消
   · 「↶ 撤销」= 回退上一步（最多 20 步）
   · 「清空本页」= 清掉本题全部高亮

4. 手写批注
   「开笔」→ 「✒ 笔」选颜色+粗细 → 在短文上拖动书写
   · 「▤ 橡皮」擦笔迹，也能擦掉五色笔高亮
   · 「撤销」撤一笔，「清空本题」清本题
   · 再点一次工具按钮 = 收起面板；点面板外也自动收起

5. 查词（教师专属）
   点短文里的单词 → 弹出音标 + 释义
   划选一整句 → 逐词释义
   「词库管理」→ 加词 / 导入 / 导出（CSV、JSON、TXT）

6. 发授权码给其他教师
   「教师设置」→ 设有效期 → 「生成 6 位授权码」→ 告诉对方
   「收回授权」= 该码立即失效

7. 看正确率
   顶部「正确率」→ 按套卷看完成率与正确率

8. 换设备 / 备份
   顶部「导出」→ JSON 文件；新设备「导入」即可

9. 翻页笔（投影用）
   PageUp = 上一题     PageDown = 下一题

────────────────────────────────────────────────────────────
【学生】
────────────────────────────────────────────────────────────
1. 做题
   顶部选套卷 → 短文里的横线直接点进去打字
   → 点「提交批改」→ 对的变绿、错的变红 + 显示答案解析
   → 「重做」= 清空本题

2. 收集生词
   点短文里的英文单词 → 自动收进单词本（底部会提示）
   再点一次 = 取消收藏
   顶部「单词本」查看全部（按收藏先后排列）

3. 划重点
   「开笔」→「▨ 记号笔」选颜色和粗细 → 拖动涂画
   不用时点「收笔」

────────────────────────────────────────────────────────────
【重要提醒】
────────────────────────────────────────────────────────────
· 数据只存在这台设备的浏览器里，不会上传！
· 清除浏览器数据 / 换浏览器 / 换设备 = 数据会丢
  → 重要作业请点「导出」备份
· 开笔（涂画）状态下点单词不会有反应，先点「收笔」
· 学生模式看不到答案，这是系统锁定的
